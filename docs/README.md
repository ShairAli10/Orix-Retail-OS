# Documentation

This directory contains human-facing product and engineering documentation.

## Structure

- `architecture/` - technical architecture, boundaries, and long-term decisions
- `development/` - local setup, tooling, workflows, and contribution guidance
- `releases/` - versioning, release notes, installer strategy, and support policy
- `operations/` - future operational runbooks for support and diagnostics
- `decisions/` - Architecture Decision Records
- `github/` - GitHub workflow, branching, pull request, and issue guidance

The `ai/` directory at the repository root is separate on purpose. It contains working context for
AI agents and should be treated as executable project memory.
