## Event Design Decisions

- Draft events may be audited only when retained or operationally meaningful.
- Posted events must be auditable.
- Derived balance change events are useful for dashboards but must not replace source events.
- Future cloud sync should prioritize immutable business facts over transient dashboard refresh
  events.
- Printer events are operational evidence, not financial truth.
