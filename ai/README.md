# AI Repository Memory

This directory gives AI assistants durable project context.

AI agents must read this directory before making architectural or implementation changes.

## Files

- `constitution.md` - non-negotiable project principles
- `architecture.md` - layered architecture and package dependency rules
- `business-rules.md` - current and future home for domain rules
- `coding-standards.md` - engineering standards for implementation
- `glossary.md` - shared vocabulary
- `prompt-library/` - reusable prompts for future work
- `acceptance-criteria/` - done definitions for milestones and features
