# Milestone 0: Foundation Acceptance Criteria

- Repository has a pnpm workspace definition.
- Repository has TypeScript project references.
- Shared TypeScript strictness is centralized.
- Package boundaries exist for desktop, business, database, UI, printer, inventory, ledger, and shared.
- Documentation exists under `docs/`.
- AI repository memory exists under `ai/`.
- GitHub collaboration guidance exists under `github/` and `.github/`.
- No POS, inventory workflow, ledger workflow, reports, authentication, or database schema is implemented.
- Architecture rules are documented for React, IPC, services, repositories, and SQLite.
