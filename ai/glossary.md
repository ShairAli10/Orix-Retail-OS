# Glossary

## Application Service

A use-case coordinator that enforces business rules and calls repositories.

## Repository

A persistence adapter that loads and saves data without business decision-making.

## Renderer

The React UI running in Electron.

## IPC

Electron inter-process communication between renderer/preload and main process services.

## Offline-First

The application must perform its core duties without requiring network access.

## Migration

A controlled database structure change that can safely run on customer machines during upgrades.

## Composition Root

The application entry point where concrete implementations are wired together.
